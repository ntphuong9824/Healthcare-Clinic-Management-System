# Document Template Skill

## Trigger

Use when user asks to create a new document or write documentation.

---

## Documentation Format

Always use this structure for new docs:

```markdown
# [Title]

**Status**: Draft | Approved | Implementation-Ready
**Owner**: [BA Lead / Tech Lead / etc.]
**Related**: [link to parent document]

## Context
[Why this document exists]

## Content
[The actual content]

## Decisions
- [DECISION] What was decided
- [RATIONALE] Why it was decided
- [ALTERNATIVES] What was rejected and why

## Open Questions
- [Question] [Owner] [Target date]
```
